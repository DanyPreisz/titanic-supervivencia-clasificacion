# Supervivencia en el Titanic — Clasificación

Proyecto de ciencia de datos listo para Google Colab. Versión completa con EDA, feature engineering, modelos, **SHAP** y más gráficos.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/titanic-supervivencia-clasificacion/blob/main/titanic_supervivencia_colab.ipynb)

> Colab requiere login de Google. Luego: Runtime → Run all.

## Contenido

- EDA completa + gráficos adicionales (pairplot, scatter, hist)
- Feature engineering (Title, FamilySize, HasCabin, Deck, FarePerPerson)
- Pipeline sin leakage
- Logistic Regression, Random Forest, Gradient Boosting
- Métricas, feature importance
- **SHAP** (summary plot + bar plot)
- Tuning y ejemplos de predicción

Dataset: https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv
