# Supervivencia en el Titanic — Clasificación

Proyecto de ciencia de datos: predicción de supervivencia de pasajeros del Titanic usando Python y scikit-learn.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/titanic-supervivencia-clasificacion/blob/main/titanic_supervivencia_colab.ipynb)

## Contenido

- EDA completa (sexo, clase, edad, familia)
- Feature engineering (Title, FamilySize, HasCabin, etc.)
- Pipeline de preprocesamiento sin leakage
- Comparación de Logistic Regression, Random Forest y Gradient Boosting
- Métricas: accuracy, F1, ROC-AUC
- Importancia de variables y tuning

Dataset público: https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv

Rango esperado en test: accuracy ~0.80-0.84, ROC-AUC ~0.84-0.88.
